# E-Commerce-Sales-Analysis
A data analysis project using SQL for data transformation and Power BI for visualization.

Data Source:
The dataset used in this project is the E-Commerce Sales Dataset sourced from Kaggle.

Direct Link: https://www.kaggle.com/datasets/berkayalan/ecommerce-sales-dataset?resource=download

Project Overview
This project explores an e-commerce dataset to uncover purchasing patterns, demographic trends, and product performance. I moved the data through a full analytical lifecycle: from raw Kaggle data to SQL transformation, and finally into a minimalist Power BI dashboard.

The "Digital Marketing" Aesthetic
In line with my brand aesthetic, this dashboard prioritizes minimalism & extreme whitespace. It is designed to be "save-worthy" and highly readable for stakeholders who need insights at a glance without corporate clutter.

Tools & Tech Stack
SQL (SQLite): Used for data cleaning, handling nulls, and complex JOIN statements to aggregate sales metrics.

Power BI: Developed a multi-chart interactive report featuring a customized "Notes App Chic" branding.

Excel: Performed initial data exploration and validation.

Project Structure
📁 CSV_Files/: Contains the CSV Files of the results of the SQL code, to be uploaded in Power BI.

📁 SQL_Scripts/: A collection of .txt files documenting the transformation logic.

📁 Dashboard/: The .pbix file for the interactive report and high-resolution preview images.

Key Insights
Demographic Split: Male customers account for ~78% of total items sold in this specific dataset.

Top Performers: Identified the "Top 10 Selling Products" to assist with inventory and marketing focus.

Trend Analysis: Visualized daily sales fluctuations to identify peak engagement periods for future campaigns.

How to Explore
View the Dashboard: Open the Dashboard/ folder and download the .pbix file to see the interactive elements like the Gender Slicer.

Review the Logic: Check the SQL_Scripts/ folder to see how the raw data was shaped before visualization.

Data Source: This project uses publicly available e-commerce data from Kaggle.
